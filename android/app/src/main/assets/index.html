新建待办

选择数值和单位后点“添加”；0表示到时提醒。需要截止时间。设置精确到秒，实际通知时间仍受系统权限与省电影响。

设置与同步

先添加组件到一张空白桌面，再长按组件，向上下左右拉伸边框。不同手机桌面可能保留固定边距。

设为0可透出桌面壁纸；过低可能影响文字对比度。所有组件共用此设置。

系统通知

未开启准时提醒时，通知可能被系统延迟。关机、强制停止应用，以及部分手机的后台限制都会影响提醒。重新打开应用后会补发错过的节点。

添加桌面小组件

如果点击添加没有弹窗，请按以下步骤操作。

  1. 返回手机桌面，长按没有图标的空白位置（部分手机需要双指捏合）。
  2. 进入“小组件 / 小部件 / 窗口小工具”，找到“不急及及代办”。
  3. 长按组件，拖到有足够空间的空白桌面页。
  4. 长按已添加的组件，拉伸边框调整到整页。

系统的“添加请求”不一定被所有手机桌面支持，软件不能绕过桌面的确认。如果组件列表中找不到，请检查是否安装在工作资料或应用分身中，并反馈手机品牌和系统版本。
