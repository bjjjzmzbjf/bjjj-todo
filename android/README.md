# 不急及及代办 · Android

安卓版 1.2.0，以可拉伸的大尺寸桌面小组件为核心，适用于 Android 8.0 及以上。

## 放到一整页桌面

1. 安装 APK 并打开一次，添加自己的待办。
2. 点击“请求添加到桌面”，无弹窗时选择“手动添加教程”，按手机桌面提示确认；也可长按桌面空白处 → 小组件 → 不急及及代办。
3. 拖到一张空白桌面，长按组件，拉伸上下左右边框。实际可用大小和固定边距由启动器决定，不能保证覆盖状态栏、底部图标栏或系统保留区域。
4. 列表可上下滚动，点方框直接完成。每页显示40项全部未完成，超过后用底部左右按钮翻页；今日区展示前5项，其余可在全部未完成中找到。

支持今日及逾期待办、全部未完成、三级重要性、五种类型、编辑、完成及恢复、多个提前提醒，以及0–100%组件背景不透明度。尺寸较小时自动省略今日区。

## 周视图与月历总览

App首页提供周日期条，可通过左右按钮切换周，点击日期查看当天未完成事项。“月总览”展示完整月份及相邻月份的日期，支持切换月份和回到今天。日期按当天未完成事项的最高重要性着色，并显示事项数量；月份视图还显示一条事项摘要。点击“这天新建”会填入选中日期的17:00，保存前可修改。完成后日期数量和颜色同步更新。过去未完成、未设置日期的事项始终留在下方“全部未完成”。

设置内的账号卡片与电脑端统一，支持登录／创建账号切换、密码显示和连接状态、最近同步、待上传数量展示。

## 事项配色

组件与App中的每条事项均按重要性显示圆角背景：重要为浅红色，普通为浅黄色，低优先级为浅蓝色。文字与勾选框采用深色，以便在桌面壁纸上辨认。

## 提醒

选择提前数值以及天、小时、分钟、秒单位，点“添加”形成提醒节点，再保存事项。可以添加多个节点，点节点旁的×移除；0表示到时提醒。旧版分钟数据保持兼容。秒是设置精度，实际通知时间受Android闹钟权限、系统休眠与厂商省电策略影响。

在设置中开启通知和准时提醒权限。不授予准时提醒权限时使用系统非精确闹钟，可能延迟；勿扰、省电、厂商后台限制、关机和强制停止也可能影响通知。重新打开后补发错过节点。通知权限由用户决定，不强制申请悬浮窗权限，未登录时可仅在本机使用；可选云同步需要网络权限。

## 数据

事项保存在应用私有目录，原子写入避免保存中断；组件和App共享数据。现已支持可选账号云同步，具体注册、离线合并和后台调度说明见 [云同步指南](../CLOUD_SYNC.md)。支持周日期切换和手机月历总览；暂不提供导入导出。卸载会清除本机数据，请谨慎。

## 构建

JDK17、Gradle8.13、Android SDK36，执行 gradle :app:assembleDebug。正式版使用项目固定签名，密钥不在仓库。GitHub Actions会构建并在Android35模拟器中验证持久化、原生组件集合展示与点击完成，通过后签名输出APK。

采用Android官方RemoteViews接口独立实现，API31以上用RemoteCollectionItems；Android8–11使用RemoteViewsService兼容。参考官方文档：https://developer.android.com/develop/ui/views/appwidgets/collections
